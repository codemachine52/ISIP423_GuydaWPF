### UP01
# 📚 Платформа для распространения книг
WPF-приложение для чтения и публикации книг.

- чтение книг пользователем;
- добавление книг автором;
- администрирование;
- жалобы на отзыв, книгу или пользователя;
- разделение ролей.

**Стек:** C#, WPF, XAML · **Запуск:** Выполнить скрипт sql в MS SQL, проверить строку подключения (в проекте файл `Core.cs`). Открыть `.sln` в Visual Studio → F5
