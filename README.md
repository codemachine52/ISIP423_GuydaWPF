## ⭐ Что внутри

**💇 Салон красоты (`PR17`)**: MS SQL, Entity Framework, валидация данных, фильтрация записей через LINQ.

**🖥️ Конфигуратор ПК (`PR15`)**: проверка совместимости процессора, материнской платы и блока питания, динамический расчёт стоимости и характеристик.

**🎬 Кинотеатр и 🛒 магазин (`pr14`, `PR13`)**: интерфейс на XAML, роли «клиент» и «администратор», каталог, корзина и оформление заказов.

**📚 Книги (`UP01`)**: чтение книг пользователем, добавление книг автором, администрирование, жалобы на отзыв, книгу или пользователя, разделение ролей.

## 🚀 Запуск

1. Установи [Visual Studio](https://visualstudio.microsoft.com/) с нагрузкой **«Разработка классических приложений .NET»**.
2. Для проектов с БД нужен **SQL Server** (например, Express) и [SSMS](https://learn.microsoft.com/sql/ssms/download-sql-server-management-studio-ssms).
3. Склонируй репозиторий и выбери ветку проекта:
   ```bash
   git clone https://github.com/codemachine52/ISIP423_GuydaWPF
   cd ISIP423_GuydaWPF
   git checkout PR17
   ```
4. Если в ветке есть скрипт БД (`.sql`), выполни его в SSMS и проверь строку подключения в классе `Core.cs`.
